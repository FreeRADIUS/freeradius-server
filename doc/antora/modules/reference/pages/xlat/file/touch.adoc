= Touch

The `file.touch` function creates a file if it does not exist. If the file already exists then this function does nothing.

[#syntax]
== Syntax

`%file.touch(_string_)`

.Return: _string_

.Ensuring a file exists
====
[source,unlang]
----
string line

line := %file.touch("/var/log/debug.log")
----
====
