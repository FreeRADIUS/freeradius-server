# Get Help

## Official Documentation

Configuration examples differ between FreeRADIUS releases. Run
`radiusd -v` to identify the installed version, then consult the
corresponding release documentation. Before copying an external
example, compare its module names, attributes, and options with the
reference documentation and default `raddb/` configuration for that
version. Test each change with `radiusd -X` on a test instance before
applying it to a running service. Project-maintained resources include:

* *https://www.freeradius.org[FreeRADIUS]*
* *https://www.inkbridgenetworks.com[InkBridge Networks]*

## How can I get training for my staff?

https://www.inkbridgenetworks.com/[Inkbridge Networks] offers a range
of training courses to meet your needs. Courses include:

* *Introduction to RADIUS* is an introductory course for all
  administrators who are unfamiliar with RADIUS. Basic RADIUS concepts
  that are key to understanding RADIUS-based systems are introduced.
* *Advanced RADIUS* is a course for senior administrators who are
  already familiar with RADIUS. It introduces advanced RADIUS concepts
  that will help system administrators design, deploy, maintain and
  debug their systems.
* *Programming with RADIUS* is a course for developers who wish to
  create their own customized solutions.

## How do I get support from a consultant?

customized RADIUS solution that meet your needs. Your customized

simultaneously. The system can include:

* EAP-TTLS

Existing systems can be migrated to our product or we can configure

that is robust, high performance, and easy to maintain. Contact us at
