= FreeRADIUS Development

As the name suggests, FreeRADIUS is developed under the GNU General
Public License, Version 2 (GPLv2). We invite anyone to use and
contribute code to the project. The following information should be
helpful to those who want to contribute.

The official FreeRADIUS v4 developer guidelines are also online at the
https://www.freeradius.org/documentation/freeradius-server/4.0.0[project's
website].

Key resources for developers include:

* GitHub repository: The source and documentation can be found in the
  https://github.com/FreeRADIUS/freeradius-server[FreeRADIUS repository].
  Contributions can be proposed using issues and pull requests.

* Development mailing list: The
  https://freeradius.org/support/[FreeRADIUS mailing lists] support
  discussion of technical development and of using the server.
  Contributors at any experience level can use the development list
  for relevant engineering questions and proposals. Configuration
  and deployment support generally belongs on the users list.

The server can be built from source by following the
xref:howto:installation/source.adoc[install from source]
documentation.

The rest of this document has various resources for developers.

== xref:bugs/bugs.adoc[Bugs]

Use the issue tracker for reproducible software and documentation
defects, with relevant evidence. For configuration or operational
questions, use the users mailing list.

== xref:coding-methods.adoc[Coding Methods]

This is a short set of guidelines to follow when programming. Coding
standards focus on function names, code appearance, and consistency.

== xref:coverage.adoc[Code Coverage]

The gcov tool analyzes your programs. It helps you create efficient
code and find untested areas.

== xref:profile.adoc[Profiling]

The gperftools (Google Performance Tools) help you find memory leaks,
analyse performance issues, and optimize your code.

== xref:coccinelle.adoc[Semantic Patches]

Coccinelle analyzes and transforms C code to create Semantic Patch
Language (SmPL) patches.

== xref:contributing.adoc[Contributing]

Use GitHub issues for defect reports and proposals, and pull requests
for concrete changes. Refer to the contribution guidance for details.
Small changes can also be made using GitHub's web editor.

== xref:module_interface.adoc[Module Interface]

The purpose of modules is to handle small, simple tasks when RADIUS
packets arrive. The module framework is built to process incoming
RADIUS packets. It is also highly customizable.

== xref:release-method.adoc[Release Method]

Review the steps to push or update a release.

== xref:buffers.adoc[Buffer Management]

FreeRADIUS provides APIs to handle xref:dbuff.adoc[Data] and
xref:sbuff.adoc[String] buffers enabling developers to streamline
their coding and processes.

== More Information

Foundational RADIUS references include
https://www.rfc-editor.org/rfc/rfc2865[RFC 2865] and
https://www.rfc-editor.org/rfc/rfc2866[RFC 2866]. Additional updates
and extensions may apply to the feature being implemented; check
the current RFC status and relevant protocol documentation.

Also see the  xref:howto:installation/dependencies.adoc[build
dependencies] page.
