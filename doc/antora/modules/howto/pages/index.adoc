= Howto Guides

The Howto guides explain worked examples of common FreeRADIUS tasks. Each guide explains a primary task or scenario. For example, it may cover installing the server or upgrading a configuration. It may also cover connecting a datastore or enabling a protocol. For more details of FreeRADIUS components see the xref:concepts:index.adoc[Concepts] section.

== xref:howto:installation/index.adoc[Installation]
Covers the available installation methods and the first install of a FreeRADIUS server. xref:howto:installation/dependencies.adoc[Dependencies] lists the libraries and tools the server needs. xref:howto:installation/packages.adoc[Install from Packages] describes using the official InkBridge Networks packages, which is the recommended approach where they are available. xref:howto:installation/source.adoc[Build from Source] describes building the server yourself, with per-platform notes for xref:howto:installation/debian.adoc[Debian and Ubuntu], xref:howto:installation/redhat.adoc[RedHat and Rocky], and xref:howto:installation/osx.adoc[OSX].

== xref:modules/configuring_modules.adoc[Configure Modules]
Describes how to test any module configuration, then provides worked examples for individual modules in common deployment scenarios. The guides cover xref:modules/chap/index.adoc[CHAP], xref:modules/eap/index.adoc[EAP] and its xref:modules/eap/eap_subtypes.adoc[sub-types], xref:modules/expiration/index.adoc[Expiration], xref:modules/krb5/index.adoc[KRB5], xref:modules/mschap/index.adoc[MS-CHAP], xref:modules/pam/index.adoc[PAM], xref:modules/passwd/index.adoc[Passwd], xref:modules/python/index.adoc[Python], xref:modules/rest/index.adoc[REST], xref:modules/sql/index.adoc[SQL], xref:modules/sqlcounter/index.adoc[SQL-Counter], and xref:modules/sqlippool/index.adoc[SQL-IP-Pool]. The xref:modules/ldap/index.adoc[LDAP] guide gives detailed steps: from xref:modules/ldap/bootstrap_openldap/index.adoc[installing OpenLDAP] and xref:modules/ldap/ldapsearch/index.adoc[testing with ldapsearch]. as well as xref:modules/ldap/authorization/index.adoc[authorization], xref:modules/ldap/authentication.adoc[authentication], and xref:modules/ldap/accounting.adoc[accounting] configurations.

== xref:datastores/index.adoc[Set up Datastores]
Outlines how to connect FreeRADIUS to the systems that hold user credentials and session data. A datastore supplies data to the server; the server performs the authentication. Guides are provided for xref:datastores/ad/index.adoc[Active Directory], including xref:datastores/ad/samba.adoc[Samba], xref:datastores/ad/winbind.adoc[Winbind], and xref:datastores/ad/ntlm_mschap.adoc[NTLM] configuration, as well as xref:datastores/ldap.adoc[LDAP], xref:datastores/redis.adoc[Redis], and xref:datastores/sql.adoc[SQL].

== xref:protocols/index.adoc[Protocols]
Covers enabling and configuring the protocols the server uses. The xref:protocols/radius/index.adoc[RADIUS] guide describes xref:protocols/radius/using_coa.adoc[Change of Authorization] with xref:protocols/radius/coa_examples.adoc[examples], and xref:protocols/radius/proxy_config.adoc[Proxy Configuration] with its xref:protocols/radius/proxy_extensions.adoc[extensions]. The xref:protocols/dhcp/index.adoc[DHCP] guide is a staged walkthrough: xref:protocols/dhcp/prepare.adoc[Preparation], xref:protocols/dhcp/enable.adoc[enabling the service], xref:protocols/dhcp/test.adoc[testing the service], and xref:protocols/dhcp/policy.adoc[defining the DHCP policy], which includes IP pool creation and access restriction.

== xref:os/index.adoc[Security Certificates]
Explains how FreeRADIUS uses digital certificates for authentication methods such as EAP-TLS. The server can generate and manage its own certificates, or you can install certificates from an external Certificate Authority. xref:os/letsencrypt.adoc[LetsEncrypt] describes using certificates from a public CA.
